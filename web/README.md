# web

Web interface layer for this repository. See
[web conventions](../.yidam/.vendor/prelude/guidelines/directories.md) for what belongs here.

The audience for this — school boards, journalists, legislative staff, parents — will not be
running a Rust CLI, so a web layer was in scope from the outset.

## What exists

**[`index.html`](index.html)** — the agency view. Pick a district and see what the Fair School
Funding Plan computes for it, what it actually receives, and where the difference comes from.
Self-contained: no build step, no framework, no external requests.

It leads with the question the corpus found most consequential. For a district on the
guarantee, the page states plainly that its funding is held at what it received in **FY2020** —
a year Ohio froze funding under the Bridge formula rather than computing it — and shows what
fraction of that level the formula now produces. For a district on formula, it says so, and
notes how many districts are not.

**[`data/bundle.json`](data/bundle.json)** — the feed, 609 districts, generated by
[`crates/bundle`](../crates/bundle/):

```
cd crates && cargo run -p bundle > ../web/data/bundle.json
```

The page reads the bundle rather than the corpus. The corpus is markdown and YAML written for
traversal; the platform needs numbers for every district. The bundle is the seam, and it
carries a `contract_version` — the page refuses to render on a version it does not recognise
rather than guessing at field meanings.

## Running it

Browsers block `fetch` from `file://`, so serve the directory:

```
cd web && python3 -m http.server 8000
```

The page says exactly this if the fetch fails, rather than showing an empty frame.

## Design notes

Two series appear — formula aid and guarantee — in the categorical slots validated for both
light and dark surfaces (`#2a78d6`/`#eb6834` light, `#3987e5`/`#d95926` dark; all six checks
pass in both modes). They carry direct labels as well as color, so identity never rests on hue
alone. Dark mode is a selected step from the same ramps rather than an inversion, and the
`data-theme` scope beats the OS setting in both directions.

Distribution position uses a marker on a neutral strip rather than a chart: the question is
"where does this district sit," which is a single value against a range, not a series.

## What is not built

The [regime view](../.yidam/corpus/funding-regime/) — walking the history from the Foundation
Program to the Fair School Funding Plan — and the scenario builder, which would let a user
perturb parameters and see per-district deltas. The scenario machinery exists in
[`crates/foundation`](../crates/foundation/) but is not wired to a UI. Deployment target is
still undecided; static hosting with this bundle is the presumption.
