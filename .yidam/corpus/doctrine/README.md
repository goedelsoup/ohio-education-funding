# doctrine

The normative frames against which Ohio's funding system is judged. These nodes are what let
the corpus answer whether a regime was constitutional or fair, rather than only what it paid.

Doctrines here are stated precisely enough to be applied. A frame that cannot be turned into a
test does no work — so each node carries a `formulation` written to be checkable, and where a
computable version exists it is linked to the [`metric`](../metric/) that operationalizes it.
That linkage is the point: adequacy becomes a comparison of spending against a costed-out
requirement, equity becomes a dispersion statistic, and both become arguments that can be
settled with data rather than asserted.

The `tensions-with` edge between [adequacy](adequacy.yml) and [equity](equity.yml) is the most
load-bearing edge in this class. Ohio has at various times pursued each at the other's expense,
and a reform described as advancing school funding is usually advancing one of them.

See the class definition: [doctrine.ont.yml](../doctrine.ont.yml).
