# docs

This repository documents how Ohio funds its public schools — the state foundation formula
and its successive regimes, the local property tax base that HB 920 froze against inflation,
the litigation that found the combination unconstitutional four times, and the programs that
divert money around the formula's edges. It is written for researchers, policy staff, agents,
and contributors who need to trace a specific dollar figure back to the statute and parameter
that produced it, and to ask what a proposed change would do to a specific district.

This directory holds documentation about this repository: its purpose, scope,
domain conventions, and any decisions that shaped its structure.

It is distinct from the corpus (which holds knowledge claims) and the prelude
(which holds yidam's own model). Documentation here describes the *repository*,
not the domain.
